# Niobium Lite for Android

This is the **only Niobium browser edition in this repository**. It is a lightweight Android browser powered by Android System WebView.

## Build on GitHub (no PC required)

1. Open **Actions → Build Niobium Lite (Android WebView APK)**.
2. Tap **Run workflow**, or push a change to the Android app or icon.
3. Wait for the workflow to finish successfully.
4. Open the completed run and download **Niobium-Lite-Android-APK** under Artifacts.
5. Extract the ZIP and install `app-debug.apk` on your Android device.

The workflow builds a debug APK for personal testing. A production release should use a securely configured signing key.
